# MONO FROG

우물 밖 하늘이 궁금해진 개구리의 흑백 픽셀 점프 게임.

힘을 모아 뛰고, 공중에서는 방향을 바꿀 수 없어요. 체크포인트는 없고, 떨어지면 아래 구역까지 굴러떨어져요.
둥근 우물이라 화면 왼쪽 끝과 오른쪽 끝이 이어져 있어요.

**플레이:** https://dobbi52.github.io/mono-frog/

## 조작
- 컴퓨터: 스페이스를 길게 눌러 힘 모으기, ← → 로 방향
- 휴대폰: 화면 아래 `<` `>` `점프` 버튼

## 구역
1. 바닥 웅덩이
2. 이끼 벽 — 미끄러운 이끼
3. 무너진 두레박 — 흔들리는 판자
4. 바람 구멍 — 박자 맞춰 부는 바람
5. 빛의 입구 — 지금까지 배운 것 모두, 그리고 우물 밖
